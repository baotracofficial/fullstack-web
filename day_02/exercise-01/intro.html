Giới thiệu bản thân - Trac Nguyen

Về tôi

Xin chào! Mình là Trac Nguyen, một người yêu thích công nghệ và lập trình web. Mình cao 165 cm và luôn cố gắng học hỏi những kiến thức mới mỗi ngày. Hiện tại, mình đang tập trung tìm hiểu HTML, CSS và JavaScript để xây dựng những giao diện web đẹp, dễ sử dụng và dễ bảo trì.

Sở thích

Mình thích khám phá công nghệ mới, đọc tài liệu lập trình và thực hành xây dựng các dự án nhỏ.

  • Học HTML và CSS theo chuẩn.
  • Viết JavaScript thuần để xử lý tương tác.
  • Tìm hiểu cách tổ chức mã nguồn dễ bảo trì.

Mục tiêu học tập

Mục tiêu của mình là nắm vững nền tảng HTML, CSS và JavaScript, sau đó áp dụng kiến thức vào những dự án thực tế.

  1. Hoàn thiện kiến thức HTML Semantic.
  2. Thành thạo CSS và phương pháp đặt tên BEM.
  3. Xây dựng các ứng dụng bằng JavaScript thuần.
